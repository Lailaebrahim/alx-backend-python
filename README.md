#alx-backend-python

This repository contains Python backend programming examples and exercises, specifically targeting asynchronous programming and testing practices.

## Contents

- **0x01-python_async_function/**  
  Demonstrates Python asynchronous programming concepts using `async` and `await`. Includes practical examples to help understand concurrency, coroutine creation, and async workflows.

- **0x03-Unittests_and_integration_tests/**  
  Contains examples of Python unit tests and integration tests. Learn how to test Python code using the built-in `unittest` module, with real-world test scenarios and best practices for backend systems.

## Getting Started

Clone the repository:

```sh
git clone https://github.com/Lailaebrahim/alx-backend-python.git
cd alx-backend-python
```

## How to Run

Each folder contains Python scripts and tests. Run scripts as usual:

```sh
python3 <script_name>.py
```

Run tests with:

```sh
python3 -m unittest discover
```
